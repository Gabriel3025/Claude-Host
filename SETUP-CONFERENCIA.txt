================================================================================
  TROUBLESHOOTING RAPIDO
================================================================================

Erro: "coleta_python.json nao encontrado"
  → python coleta_robusta.py

Erro: "Credentials nao encontrado"
  → node reauth.js (renovar token Google)

Erro: Playwright timeout (muito lento)
  → Aumentar timeout em coleta_robusta.py (linha ~70)

Erro: Valores muito altos ou 0 em tudo
  → Verificar se Facebook mudou o layout da Ads Library
  → Testar URL manualmente no navegador

Valores discrepantes apos escrita
  → node verificar-coleta.js (detecta automaticamente)

Script preso/nao responde
  → Ctrl+C para cancelar
  → Esperar 5 min e tentar novamente
