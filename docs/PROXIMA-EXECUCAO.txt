================================================================================
                         TROUBLESHOOTING 30-SEG
================================================================================

PROBLEMA: Script nao funciona
  1. Ctrl+C para cancelar
  2. Fechar todos os outros PowerShells/Python
  3. Esperar 30 segundos
  4. Tentar novamente: node conferencia-ofertas.js

PROBLEMA: "Credentials nao encontrado"
  → Rodar: node reauth.js
  → Isso renovara o token Google

PROBLEMA: Valores muito altos ou muito baixos
  → Testar manualmente no navegador
  → Facebook pode ter mudado o layout da Ads Library
  → Se nao conseguir resolver: avisar para revisar

PROBLEMA: Desalinhamento detectado na verificacao
  → Nao deve acontecer! (foi corrigido)
  → Se acontecer: avisar imediatamente
  → Problema pode estar no Google Sheets API
