================================================================================
                           FLUXO DE EXECUCAO
================================================================================

DIA 2+ (sempre igual):

    1. node conferencia-ofertas.js
       ├─ python coleta_robusta.py
       │  └─ gera coleta_python.json
       ├─ node escrita_robusta.js
       │  └─ escreve na planilha
       └─ gera relatorio_ofertas.json

    2. node verificar-coleta.js
       ├─ le coleta_python.json
       ├─ compara com read_sheet.js
       └─ relatorio de integridade

    3. git add . && git commit && git push
