## 🚀 Como Usar

```bash
# Desenvolvimento local
cd clone-tdah-focado
npm run dev

# Build para produção
npm run build
npm start

# Deploy Vercel
npx vercel
```

## 🎨 Design

- **Cores:** Marrom (rgb 124,45,18) + Orange (rgb 255,140,0)
- **Tipografia:** Poppins (Google Fonts)
- **Layout:** Single-column centered (max-w-3xl)
- **Background:** Gradiente quente (bege → creme)

## 📁 Arquivos-chave

- `src/components/` — 10 componentes React
- `src/app/layout.tsx` — Setup de fontes/metadata
- `src/app/globals.css` — Design tokens
- `docs/research/` — Specs e topologia

## 🔧 Stack

- Next.js 14 (App Router)
- Tailwind CSS v4
- TypeScript
- Poppins font (Google Fonts)

## ✏️ Customização

### Link CTA
Procure por `https://pay.wiapy.com/...` em `src/components/CTASection.tsx`

### Conteúdo
Edite `src/components/` ou leia `docs/research/CONTENT.md`

### Cores
Modifique `src/app/globals.css` (variáveis CSS)
